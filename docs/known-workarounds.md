# Known workarounds

The playground's own code works around a few upstream bugs: in its own pages (home, compare, matrix, sizes), its toolbar or its build. Each workaround hides a bug from whoever uses the playground, so each one is listed here with the issue that tracks the bug and how to tell when it can go. Pages under test never get one: a Bootstrap bug shows there as it is, and the test suites allowlist it with its tracking issue (see [Upstream issue tracking](../CLAUDE.md#upstream-issue-tracking)).

Add a row whenever the playground's code steps around a bug, and point the code's comment at the tracking issue. When the issue closes, remove the workaround and its row in the same pull request.

## Not workarounds

These look like workarounds but are choices, so they stay:

- The toolbar ([`src/js/toolbar.js`](../src/js/toolbar.js)), the page switcher ([`src/js/palette.js`](../src/js/palette.js)) and the tab order overlay ([`src/js/tab-order.js`](../src/js/tab-order.js)) render in shadow roots with their own colors and their own focus ring (`outline: 2px solid #7aa7ff`). They follow no Bootstrap token on purpose, so a config or a color mode under test never changes them, and they never leak into the page.
- The home page's cards ([`src/home.css:646`](../src/home.css#L646)) remove the focus outline of their stretched link and draw the ring on the whole card with `:has()`, so the ring follows the card's shape. It has nothing to do with the chips' missing focus ring ([#7](https://github.com/julien-deramond/bootstrap-test-playground/issues/7)), which the kitchen sink shows as it is.
- Some pages list upstream issues in their notes, like [`pages/color-modes.html`](../pages/color-modes.html), [`pages/custom-property-prefix.html`](../pages/custom-property-prefix.html), [`pages/grid-only.html`](../pages/grid-only.html), [`pages/sass-api.html`](../pages/sass-api.html), [`pages/utilities-only.html`](../pages/utilities-only.html) and [`pages/utility-api.html`](../pages/utility-api.html). They show the bugs rather than hide them: they're reproductions, tracked in [`issues/`](../issues/) and on the home page.
