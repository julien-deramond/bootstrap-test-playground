Shadow DOM

Bootstrap's compiled CSS adopted in the shadow roots of two custom elements, one with data-bs-theme="dark" on its host. Each shadow root holds buttons, a menu, a tooltip, a dialog and a form.

The tokens are declared on :root, :host, so they should reach a shadow root. Bootstrap's JavaScript listens on document, so the data API may not see inside one: each root starts its components both ways, with data-bs-toggle and with new bootstrap.Menu() and friends. See #78.
