Sass API

Everything here comes from configs/mixins/, built with Bootstrap's documented mixins and functions. Its Sass checks what each function returns, so a rename or a changed result fails the build.

A custom component: .callout

tokens() with a defaults() map, --theme-* with fallbacks, border-radius(), transition(), focus-ring() (tab to one), media-breakpoint-up() for the padding, color-mode(dark) for a dashed edge, color-scheme(dark) for the icon, mask-icon() with escape-svg(), and visually-hidden() for the label.

Note: Without a theme class, the callout falls back to --bg-1 and --border-color.

Note: With .theme-primary, it reads the theme's subtle background, border and emphasis text.

Warning: Any theme works, .theme-warning here.

Danger: Inside .sass-api-themes, the theme class comes from generate-theme-classes(), included again there.
