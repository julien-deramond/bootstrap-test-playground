Large table

1000 rows from a seeded generator, so every load shows the same data. The header is sticky, the navbar is fixed, and the wrapper decides which of the two scrolls.

The three wrappers differ in who scrolls. None leaves the page to scroll: the header sticks under the navbar. Responsive is .table-responsive, which scrolls sideways when the table is wider than the container, and then also becomes the box the header sticks to. Fixed height gives that wrapper a height, so the header sticks inside it. The state is in the URL (?variants=striped,hover&wrapper=box&rows=200).
