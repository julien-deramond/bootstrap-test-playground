The color-mode() mixin

v6 resolves color modes with color-scheme: the system preference, overridden by the nearest data-bs-theme. The mixin emits either a prefers-color-scheme media query or a [data-bs-theme="dark"] ancestor selector. Each probe gets an outline when the mixin's dark rule applies, and passes when that matches its own color mode. Change the toolbar's color mode, or the system's, to see the other cases.

Custom color modes

Each color mode these styles define, Bootstrap's dark first as a reference, is set on <html> in turn, as the toolbar does. It passes color-scheme when its rule sets color-scheme, so the light-dark() tokens it doesn't override stop following the system. Each overlay passes when it opens with the page's color-scheme and --bs-bg-body. configs/color-modes-custom defines blue (the docs' example), sepia and dim.
