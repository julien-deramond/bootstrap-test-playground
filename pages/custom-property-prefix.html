Custom property prefix

Every place where Bootstrap's JavaScript reads or writes a custom property that the CSS also uses, checked under the prefix the page's styles were compiled with.

Upstream: #196 (the JavaScript hard-codes --bs-) and #197 (the strength text never takes its color), not reported yet

What this checks

The docs say the bs- prefix comes from PostCSS and can be changed with its prefix option, and their npm and webpack guides don't add the prefix at all. Bootstrap's JavaScript, though, uses the --bs-* names. These styles define …. Compare with configs/prefix-x (--x-*), configs/prefix-none (no prefix) and the defaults, or use the toolbar's Styles menu.

The prefix doesn't touch data-bs-* attributes or the .bs-popover-* and .bs-tooltip-auto classes, which aren't custom properties. Responsive placement hard-codes the breakpoints whatever the prefix (#191).
