Layout: CSS grid

.grid with g-col-* and g-start-*. Each grid is a size container (container-type: inline-size), so its responsive classes, like md:g-col-6, follow the grid's own width and not the viewport's. It needs $enable-cssgrid, which the grid-flex-only config turns off. See also the flexbox grid and containers.
