Layout: containers

.container grows its maximum width at each breakpoint, .container-fluid never stops, and a responsive container (md:container) is fluid until its breakpoint. Each example prints its measured width. The second half puts a CSS grid and a flexbox .row in wrappers you can resize: the grid follows the wrapper, the row follows the viewport until twbs/bootstrap#42784 lands. The prefixes are the config's: with breakpoints-custom, md:container doesn't exist. See also the flexbox grid and CSS grid.

Container queries

The same classes in a CSS grid and in a flexbox row, in wrappers of fixed widths (the last wrapper is also resizable: drag its corner). The grid’s md:g-col-6 and xl:g-col-3 follow the wrapper. The row’s md:col-6 and xl:col-3 are media queries: they follow the viewport, so the row only matches the grid when the wrapper is as wide as the viewport.
