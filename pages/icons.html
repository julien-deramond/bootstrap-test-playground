Icon integration

The same icons in every slot v6 gives them, once per source: Bootstrap Icons as a font and as an SVG sprite, Lucide as inline SVG, and an emoji. The icon names match across sources, so a difference comes from the integration, not from the glyph.

Icon sizing and alignment depend on 1em against fixed sizes and on currentColor. Switch the direction in the toolbar (?dir=rtl): the arrows and chevrons are mirrored with scale: -1 1 on :dir(rtl), which neither icon set does for you. Every icon here is decorative and hidden from assistive technology, and every icon-only button has an accessible name. See #81.

Bootstrap Icons font

The icon font: <i class="bi bi-search">. The glyph is a ::before character, so it follows font-size and color but not the width and height a slot sets.
