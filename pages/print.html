Print

An invoice to look at with print emulation (the visual suite's print captures) or the browser's print preview.

Bootstrap v6's default build has no @media print rule. The only print support is the utility API's print: true key, which no default utility sets, so this page loads the utilities-custom config, where opacity has .print:opacity-* classes. The toolbar's Styles menu doesn't apply here.

What to look at

  • The Download and Pay online buttons have .print:opacity-0. They become transparent in print but keep their space, because the utility API only generates opacity here, not display.
  • Badges, the colored card and the table stripes use backgrounds. Browsers drop backgrounds when printing unless print-color-adjust: exact is set, which Bootstrap never sets. Print emulation in a screenshot doesn't drop them, so check the print preview's Background graphics option.
  • The dark card has an explicit data-bs-theme="dark". Browsers print with light colors whatever the OS color scheme is, but an explicit dark theme stays dark.
  • The table has enough lines to run over two pages. Look at where it splits, and whether the header repeats and a row is cut in two.
  • The sticky bar, the open dialog and the open menu show what overlays do at print time.
