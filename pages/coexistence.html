Coexistence with third-party CSS

Bootstrap v6 puts its styles in cascade layers, and most other CSS isn't in one. A rule outside every layer beats every layered rule, whatever the selectors' specificity, so a legacy stylesheet or Tailwind's preflight loaded next to Bootstrap wins over its reboot, components and utilities. Wrapping the third-party CSS in a layer that is declared before Bootstrap's puts it under Bootstrap instead. Third-party CSS has the guidance.

Each case below has its own scoped stylesheet in pages/coexistence.css. The scopes use :where(), which adds no specificity, so a rule's layer is the only thing that decides. A case passes when the rule the cascade says should win wins; an unlayered rule winning is the pitfall itself, not a Bootstrap bug.
