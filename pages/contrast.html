Contrast

Every documented color pairing, for every theme color, and the components that embed one, in every color mode of the current config.

Each foreground is composited on what's behind it, then measured: the WCAG 2 ratio, AA at 4.5:1 and AAA at 7:1 for normal text, and the APCA Lc for reference. Disabled controls are measured but exempt (WCAG 1.4.3). The live sample shows the current color mode, the swatches the colors measured in each mode. See #52, and npm run report:contrast for every config.

Theme colors

The pairings of the theme docs: contrast on bg and base, fg on bg-subtle, bg-muted and the body, fg-emphasis on bg-muted.

Body and surfaces

fg-body on every background, fg-1 on bg-body to bg-3, fg-2 to bg-2, fg-3 to bg-1: the dimmer the text, the fewer the backgrounds.

Components

Components whose defaults embed a pairing, on bg-body, measured on the element itself.
