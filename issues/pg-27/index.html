Upstream: #148 (drawer tokens) and #149 (.fade, .collapse), not reported yet

What this checks

Bootstrap declares @layer colors, config, root, reboot, layout, content, forms, components, custom, helpers, utilities. The README's customization rules depend on that order. Global tokens stay unlayered, in tokens.css. Component tokens and rules go in @layer custom, in _custom.scss, which wins over components and loses to helpers and utilities.

Each check below uses the override in this reproduction's tokens.css or _custom.scss. Those overrides use :where(), so their specificity is 0 and only layer order can make them win. The marker compares the computed style with what the rule promises. npm run audit-layers -- --render reads the same markers.
