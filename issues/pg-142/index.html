Issue pg-142

Steps to reproduce

  1. Open this page with ?dir=rtl.
  2. Hover (or keyboard-focus) the .icon-link.icon-link-hover link: its trailing icon sits on the left in RTL.
  3. Read the horizontal translation of the icon.

Expected

In RTL the icon moves left, away from the text: a negative x translation. In LTR it keeps moving right by .25em.

Actual

The icon moves right in RTL, into the text, because --icon-link-icon-transform is translate3d(.25em, 0, 0) with no direction flip. The spec repro.spec.js measures it, as hovering is a state this page can't show on its own.
