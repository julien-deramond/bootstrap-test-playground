Issue pg-210

Steps to reproduce

  1. Inspect the label of the floating input below.
  2. Read its computed color and compare it with its parent's.
  3. Set --bs-form-floating-label-opacity to 30% on the field and read the label's color again.

Expected

The label shows at 65% of the body text color, and the token changes it.

Actual

The label has the same color as its parent. --bs-form-floating-label-opacity is .65, which color-mix() rejects as a percentage, so the declaration is invalid at computed-value time and the token has no effect.
