Static menus have no positioning rule

Steps to reproduce

  1. Open each menu below. The two static ones (data-bs-display="static") sit in a .position-relative wrapper, the first a block, the second a .d-flex gap-2 row. The dynamic one is the control.
  2. Measure the gap between the bottom edge of the toggle and the top edge of the menu, and between their start edges.

Expected

A static menu opens below its toggle, lined up with its start edge, with the same 2px gap (--menu-spacer) as a dynamic menu, whatever the wrapper's layout.

Actual

No rule reads data-bs-display, so the menu stays at its static position: 0px below the toggle in a block wrapper, and 38px above its bottom edge, on top of the toggle, in the flex row. The dynamic menu is 2px below.
