Issue pg-329

Steps to reproduce

  1. Open this page in Firefox or WebKit with ?dir=rtl. The slots run right to left: the first digit goes in the rightmost slot.
  2. Click the first input and type 1 2 3. The active slot is the fourth, just left of the 3.
  3. Press → twice, then ← three times, and watch the active slot after each key. repro.spec.js does these steps and reads the active slot.

Expected

Each arrow moves the active slot one slot in the direction it points, in every engine. From 123 the active slot goes 2, 1, 2, 3, 3 (the Chromium result). Keeping the slots left to right in RTL would also do, if the arrows then match them.

Actual

In Firefox → does nothing and ← moves the active slot to the right (3, 3, 2, 1, 0). In WebKit it jumps back and forth (1, 2, 1, 3, 3). Chromium is correct, so this page shows no failure there.
