Issue pg-324: Datepicker dispose replaces the input

Steps to reproduce

  1. Click Create, dispose and re-initialize below. It creates a Datepicker on the input, calls dispose(), then creates a new instance on the same input and calls show().
  2. Read the two checks in the result line: is the input still in the document, and is the new calendar in the document.

Expected

dispose() leaves the input in place, as every other component leaves its element. The second instance shows its calendar.

Actual

dispose() replaces the input with a copy made when the instance was created. The input the page holds is no longer in the document, and the second instance fires show and shown without showing a calendar.
