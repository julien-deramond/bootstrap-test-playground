Issue pg-254

Steps to reproduce

  1. Hover, press or check any button below, in light and in dark mode.
  2. Read the resolved color and background-color of the button in that state: --btn-hover-color and --btn-active-color go through oklch(from … calc(l * .9) …) like the background does.
  3. Compute the contrast ratio. The spec in repro.spec.js does it for every theme color, in the hover, pressed, .active and checked states.

Expected

A state darkens the background and keeps the contrast color, so the text is never harder to read than at rest.

Actual

The text color is darkened by the same step as the background, so the ratio drops below the rest state (3.32:1 on an active primary button, 3.56:1 at rest).
