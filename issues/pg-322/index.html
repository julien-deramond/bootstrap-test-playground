Tooltip and popover ignore data-bs-config

Steps to reproduce

  1. The two buttons below carry only data-bs-config='{"customClass":"from-config","placement":"bottom"}'.
  2. The page creates a Tooltip on the first and a Popover on the second, each with { title: 'Tip' }, and reads the options each instance got.
  3. Compare with from-config and bottom. The JS API page has the same check in its option precedence table.

Expected

Both instances get customClass: 'from-config' and placement: 'bottom', as with data-bs-custom-class and data-bs-placement. A data-bs-* attribute beats data-bs-config, and a JavaScript option beats both.

Actual

Both get the defaults, customClass: '' and placement: 'top'. data-bs-* attributes and JavaScript options work; only data-bs-config is dropped.
