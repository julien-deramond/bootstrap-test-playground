Issue pg-9: range track shadow

Steps to reproduce

  1. Render a range with the defaults, where $enable-shadows is true.
  2. Look at the track and inspect --range-track-box-shadow on the range.

Expected

The track either gets its inset shadow back, with --range-track-box-shadow declared in the range token map, or nothing reads that token any more. Either way no rule reads a token that no map declares.

Actual

The range track reads var(--range-track-box-shadow) and no map declares it, so the declaration is invalid and the track has no shadow.
