Issue pg-326

Steps to reproduce

  1. Open this page with ?dir=rtl, based on the Chips: Chip input docs example. The chips run right to left, so the input is at the left end of the field.
  2. Click the empty input, then press →, toward the chips: nothing happens. Press ←: the last chip, on the right, gets focus.
  3. On a chip, press ←: focus moves right, to the previous chip. Shift+← extends the selection the same way. repro.spec.js does these steps and reads where focus goes.

Expected

The arrows follow the layout, as the docs' keyboard tables describe in LTR. → from the start of the input focuses the last chip, → on a chip moves to the previous one, ← moves to the next chip or back to the input, and Shift+→ extends the selection toward the first chip.

Actual

The LTR keys, so every arrow points away from where focus goes: ← from the input focuses the last chip, on the right, and ← on a chip moves right, to the previous chip. Bootstrap's js/src/chips.ts handles ArrowLeft and ArrowRight without checking the direction.
