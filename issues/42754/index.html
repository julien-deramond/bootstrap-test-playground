Issue #42754: .drawer-sheet ignores .drawer-start and .drawer-end

Steps to reproduce

  1. Start from the Drawer: Sheet docs example, which uses .drawer-bottom.
  2. Open the three sheets below: the docs' .drawer-bottom, then .drawer-start and .drawer-end.
  3. Compare where each one sits. The docs say the sheet works with any placement.
  4. Fix in flight: twbs/bootstrap#42755.

Expected

The start and end sheets are flush with the left and right edges of the viewport, full height, as the bottom sheet is flush with the bottom edge.

Actual

.drawer-sheet sets left: 0, right: 0, width: 100vw and margin-inline: auto whatever the placement, so the start and end sheets span the whole width below lg, and from lg are 760px wide and centered, between the top and bottom insets.

Measured here: open a sheet

Reproduction

Bottom sheet
Flush with the bottom edge, as documented.
Start sheet
Should be flush with the start edge, full height.
End sheet
Should be flush with the end edge, full height.
