Issue pg-327

Steps to reproduce

  1. Start from the Carousel: Top controls docs example, copied below.
  2. Open this page with ?dir=rtl. The slides run right to left, and the Next control and its icon point left.
  3. Focus the Next control of the carousel, then press ← and → and watch which slide becomes active. repro.spec.js does these steps, and runs the same keys in LTR as a control.

Expected

In RTL, ← shows the next slide and → the previous one, like the mirrored controls and the scroll direction. In LTR, → stays the next slide.

Actual

In RTL, → shows the next slide, which comes in from the left, and ← the previous one. _keydown() in js/src/carousel.ts maps the keys without checking isRTL().
