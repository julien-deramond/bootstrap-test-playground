Issue #39257: Floating labels with date and time inputs

Steps to reproduce

  1. Start from the Floating labels docs example, copied below with the date and time input types, and a text input to compare.
  2. Leave them empty, then pick a value.
  3. Fixed by twbs/bootstrap#42833 (0b62385), which the installed Bootstrap includes: the page shows the fix. Before it, these inputs never matched :placeholder-shown, so they kept the resting padding and the label sat on the browser's own mm/dd/yyyy placeholder.

Expected

The label of a date or time input always floats, above the browser's placeholder or the value, which sits as low as the text input's value.

Actual

Fixed upstream: the labels float. Before the fix, the label rested on top of the placeholder.
