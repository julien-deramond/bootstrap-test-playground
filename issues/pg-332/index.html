Issue pg-332: utilities and gutters ignore a runtime token override

Steps to reproduce

  1. Open tokens.css next to this page: it sets --spacer-3: .75rem and --radius-5: .25rem on :root, both different from the .5rem defaults.
  2. Compare each utility below with the control next to it, which reads the token directly. The table lists the computed values.

Expected

The utilities follow the tokens, as .rounded-pill already does with var(--radius-pill): .p-3, .gap-3, the .g-3 gutter and .rounded / .rounded-5 match their controls (.75rem and .25rem).

Actual

The components move, but .p-3, .gap-3, .g-3, .rounded and .rounded-5 keep .5rem, because their values are written from $spacers and $radii at compile time. .rounded-top already follows --radius-5. Negative spacers (.ms--2) are left out: they have no token of their own.
