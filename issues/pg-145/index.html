Issue pg-145

Steps to reproduce

  1. Turn on reduced motion (the operating system setting, or Emulate CSS media feature prefers-reduced-motion in the browser's devtools).
  2. Compare the three spinners below: the border and grow spinners rotate and pulse more slowly, the custom SVG spinner does not.

Expected

Under prefers-reduced-motion: reduce, .spinner-rotate slows down like the other spinners: its animation-duration is 1.5s.

Actual

.spinner-rotate keeps animation: 1s linear infinite spinner-border: the reduced-motion block only sets --spinner-animation-speed on .spinner-border and .spinner-grow, and the rotate spinner doesn't read that token.
