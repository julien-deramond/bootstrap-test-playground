Issue pg-218: color-contrast() fails to compile

Steps to reproduce

This page can't call color-contrast() in its own Sass: the build would break. The verdict comes from repro.spec.js, which compiles these two snippets in Node with the Bootstrap this playground builds with (npm run check-issues -- pg-218).

@use "bootstrap/scss/functions" as *;
.a { color: color-contrast(#0d6efd); }
@use "bootstrap/scss/functions" as *;
@use "bootstrap/scss/colors" as *;
.a { color: color-contrast($blue); }

Expected

Both compile and return the most readable of $color-contrast-light, $color-contrast-dark, white and black, as the Sass functions documentation says.

Actual

Neither compiles. The first fails with $color: color-mix(in srgb, white, #0d6efd, 100%) is not a color.: opaque() returns a CSS color-mix(), which luminance() can't read.
