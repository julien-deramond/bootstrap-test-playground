Issue pg-193

Steps to reproduce

  1. Compile Bootstrap with dark: true on the bg-color utility, as this page's utilities-custom config does, so .dark:bg-primary exists.
  2. Put .bg-2 .dark:bg-primary in a subtree forced to a color mode with data-bs-theme. The plain .bg-2 and .bg-primary boxes next to it show what each mode should give.
  3. Open the page once with the system in light mode and once in dark mode. In one of the two, a forced subtree gets the other mode's background.

Expected

Each .dark:bg-primary box looks like the plain reference of its own color mode: .bg-primary under data-bs-theme="dark", .bg-2 under data-bs-theme="light", whatever the system prefers. The color modes docs say data-bs-theme="dark" forces dark mode regardless of the system setting.

Actual

The dark: rules sit in a bare @media (prefers-color-scheme: dark), which can't see data-bs-theme. The box follows the system, not the element's color mode, so some cases fail on any system.
