Issue pg-181

Steps to reproduce

The same calendar is in the Datepicker kitchen sink page, and the color modes page measures it per mode.

  1. Set the system to light mode. The page is dark: <body> has class="color-scheme-dark", Bootstrap's own utility, and the color mode is not set through data-bs-theme.
  2. Look at the first calendar. It sits straight on the dark page. The second sits in a wrapper that only has style="color-scheme: dark", which the proposed fix would also cover. The third is the control: data-bs-theme="dark" on its wrapper.
  3. The Playwright spec measures each calendar's computed color-scheme and background-color with the system forced to light, and takes the second calendar with the page itself left light, so the wrapper is the only thing that makes it dark.

Expected

The calendar inherits the color scheme of where it is rendered, so it is dark on a dark page and inside a dark wrapper.

Actual

The first two calendars are white: [data-vc="calendar"] sets color-scheme: light dark, which resets what it inherits back to the system preference. Only the control, which carries a data-bs-theme, is dark.

Reproduction

1. Page made dark with .color-scheme-dark on the body

2. Wrapper made dark with style="color-scheme: dark"

3. Control: data-bs-theme="dark" on a wrapper
