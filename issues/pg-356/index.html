Issue pg-356

Steps to reproduce

  1. Press Tab once: the first input gets focus and its calendar opens.
  2. Press Tab to move through the calendar (previous month, month, year, next month, then a day), until the last control has focus.
  3. Press Tab again. Focus should close the calendar and move to the "Next stop" button right after the input. Instead it leaves the document, and the calendar stays open. repro.spec.js does these steps for the first input, and for the second one after a day has been selected in it.

Expected

Tab on the last control of the calendar closes it and focuses the input's next tab stop.

Actual

The popup is the last child of <body>, so Tab leaves the document (to the address bar in a browser). No focusin reaches the page, so the calendar stays open and the next Tab starts again from the top.
