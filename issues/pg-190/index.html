Issue pg-190

Steps to reproduce

  1. This page uses the breakpoints-custom config: md is renamed tablet and 3xl is added, with $container-max-widths: (md: null, 2xl: null, tablet: 720px, 3xl: 1800px).
  2. Resize the window to 800px, 1100px, then 1400px wide (or run npm run check-issues) and read the width of the two samples below.

Expected

The containers widen with the viewport: 720px at 800px, 960px at 1100px, 1200px at 1400px, and the two samples have the same width.

Actual

The merged map is sm, lg, xl, tablet, 3xl, so the tablet rule (720px) comes after the lg and xl ones and wins from 768px up. .container stays 720px wide at 1400px while .xl:container is 1200px.
