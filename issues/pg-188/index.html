Issue pg-188

Steps to reproduce

  1. Put a checkbox, a radio and a switch at each size (-sm, default and -lg) in a .form-field next to a one-line label, with the large-type config.
  2. For each control, measure its vertical center minus the vertical center of its label's first line, at a 1100px wide viewport.
  3. The default config gives +3px on the large size, -0.5px on the small one.

Expected

Every control is centered on the first line of its label, within 0.5px, whatever the label's font size and line height.

Actual

The control keeps a fixed margin-block (.125rem, .375rem for the large size), which only centers it for a label whose line is as tall as the default one.
