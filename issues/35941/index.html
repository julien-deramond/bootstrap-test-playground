Issue #35941: Forced colors adaptations

Steps to reproduce

  1. Turn on forced colors: a Windows contrast theme, or in Chromium's DevTools, Rendering, “Emulate CSS media feature forced-colors: active”.
  2. Compare each pair below: their only difference is a state that Bootstrap draws with a background color.
  3. A feature request since v5, with a first proposal in the issue: @media (forced-colors) { button { outline: 1px solid LinkText !important; } }. The playground's forced colors coverage is #106.

Expected

With forced colors, buttons look like buttons, and every state below stays visible: checked, on, active, the progress value.

Actual

The CSS has no forced-colors rule. Forced colors drop backgrounds, so in Chromium a checked checkbox, a selected radio, an on switch and the active nav pill look like their counterparts, and the progress bar disappears. Buttons keep a border.
