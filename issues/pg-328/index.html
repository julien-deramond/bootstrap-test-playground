Issue pg-328: link toggles and Space

Steps to reproduce

  1. Start from the Collapse, Menu and Drawer docs examples, copied below.
  2. Focus a link toggle (<a role="button">) with Tab.
  3. Press Space. Then do the same on the <button> toggle next to it, which works.

Expected

Space toggles a link with role="button", as it does a <button>, and the page doesn't scroll (WAI-ARIA button pattern).

Actual

Nothing toggles, aria-expanded stays false (the drawer stays closed) and the page scrolls. The data APIs only listen to click, which a link fires on Enter but not on Space.
