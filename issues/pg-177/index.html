Nav pills and form range hard-code their pill radii

Steps to reproduce

  1. This page compiles Bootstrap with the square config: $radius: 0 and :root { --bs-radius-pill: 0; } in tokens.css (Sass can't set it, see #176).
  2. Look at the chip, the nav pills and the range. The chip reads --radius-pill and is square, so it proves the page sets the token.
  3. Measure the radius of .nav-pills and its links, and the --bs-range-track-border-radius and --bs-range-thumb-border-radius tokens of the range, whose track and thumb are pseudo-elements that JavaScript can't read.

Expected

Everything pill-shaped follows --radius-pill, as the chip does: the nav pills and the range track and thumb are square.

Actual

.nav-pills and its links keep a 3rem radius, and the range track and thumb a 1rem radius, because their tokens are set to those lengths instead of var(--radius-pill) (scss/_nav.scss and scss/forms/_form-range.scss). The switch also keeps 10rem; whether it should follow the token is left to upstream, so the check ignores it.
