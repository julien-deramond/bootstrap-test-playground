Issue pg-325

Steps to reproduce

  1. Start from the Tab: Nav tab docs example, copied below.
  2. Open this page with ?dir=rtl. The tabs run right to left: Home is the rightmost, Profile is on its left.
  3. Focus the Home tab and press ←, toward Profile. repro.spec.js does these steps, and runs → in LTR as a control.

Expected

In RTL, ← selects the next tab, the one on its left, and → the previous one, as the ARIA Authoring Practices ask for horizontal widgets. In LTR, → stays the next tab.

Actual

In RTL, ← selects the previous tab: from Home it wraps to Contact, the leftmost one. _keydown() in js/src/tab.ts sets isNext from ArrowRight and ArrowDown without checking isRTL().
