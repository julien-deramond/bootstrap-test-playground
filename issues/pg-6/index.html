Issue pg-6: combobox overflow

Steps to reproduce

  1. Start from the Combobox: With form field docs example, copied below.
  2. Make the .form-field 200px wide, and pre-select an option with a long label.
  3. In the second field, add min-width: 0 to the toggle.

Expected

Both toggles fit their field, and the value ends with an ellipsis.

Actual

The first toggle overflows its field: in the .form-field grid, its automatic minimum width is its content's. The second one fits, but its value is cut off with no ellipsis: .combobox-value is display: flex, so text-overflow doesn't apply to its text.
