Steps to reproduce

  1. Open this page: each field below holds a value, so its label is already floated. The first block is dir="ltr", the second dir="rtl".
  2. Compare where the floated label starts with where the text of the input starts, from the inline start edge of the field.

Expected

In RTL the floated label lines up with the start of the input text, within 1px, as it does in LTR (16px from the inline start).

Actual

In RTL the floated label starts 35px to 38px from the inline start in Chromium (16px expected): transform-origin: 0 0 and translateX(.15rem) are physical, so scaling pulls the label toward the left corner and the nudge goes the wrong way.
