Issue pg-334: $root-tokens cannot override a generated token

Steps to reproduce

  1. Open main.scss next to this page: it passes five keys to $root-tokens in @use "bootstrap/scss/bootstrap" with (…), and tokens.css stays empty.
  2. Read the table below: the computed value of each token on :root, next to the value passed.

Expected

Every key passed in $root-tokens wins over the default, whether Bootstrap writes it by hand or generates it from a map: --bs-radius-5 is .25rem, --bs-primary-bg is the teal 600, --bs-bg-body is #f8f9fa and --bs-font-size-md is 1.25rem.

Actual

Only the control --bs-spacer takes its override. The four generated keys keep their defaults, because the loops in scss/_root.scss write them after the passed map is merged. The same two lines in tokens.css (the runtime path) would work.
