What this checks

The config merges its changes into $utilities before it loads Bootstrap. This page always uses that config, whatever the toolbar's Styles menu says. Each marker compares a computed style with what the utility API docs promise. States and print can't be triggered reliably from a script, so their checks look for the generated rules and check that nothing applies at rest. Hover or focus the button and use print preview to see them.
