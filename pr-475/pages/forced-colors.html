Forced colors

With forced-colors: active, the browser replaces the page's colors with the user's system colors. A component that shows its state with a background color alone then looks the same in both states. Each row below renders one component in both states, so the two can be compared with forced colors on.

Turn forced colors on with a Windows contrast theme, or in Chromium's developer tools, Rendering, Emulate CSS media feature forced-colors. The visual suite captures this page and every kitchen sink example with it emulated (tests/visual/forced-colors.spec.js). Bootstrap has no forced-colors rule yet: #305 tracks it, with twbs/bootstrap#35941 upstream. Its reproduction is issues/35941. See #106.

Forced colors here: …. The system colors are Canvas (page background), CanvasText (text), LinkText, ButtonFace and ButtonText (buttons), Field and FieldText (inputs), Highlight and HighlightText (selected items) and GrayText (disabled text). forced-color-adjust: none opts an element out of the replacement, and forced-color-adjust: preserve-parent-color keeps its color inherited.
