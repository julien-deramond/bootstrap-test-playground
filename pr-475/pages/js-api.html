JavaScript API

Every component driven from JavaScript, where framework integrations break: getInstance, getOrCreateInstance, the component's methods, dispose() and re-init, with a log of every *.bs.* event and its relatedTarget.

Methods that return a promise log when it resolves, which should come right after the matching shown, hidden or closed event. Cancel next calls preventDefault() on the next event that starts the action. Mount a copy adds the markup again, with new ids, after Bootstrap has loaded, as a framework would, and the buttons then drive that copy. The page only uses window.bootstrap, so it works with ?js=dist too. The smoke suite asserts the precedence and the event order. See #77.

Option precedence

Bootstrap merges a component's defaults, then data-bs-config, then its data-bs-* attributes, then the options passed in JavaScript, the latest winning. Each row sets one option on a fresh copy of the component's markup, from each source in turn, and reads what the instance got. getOrCreateInstance(element, options) ignores the options when the element already has an instance; after dispose(), it creates a new one with them.
