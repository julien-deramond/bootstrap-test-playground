Issue #42621: Dialog content overflows on short viewports

Steps to reproduce

  1. Start from the Dialog docs example, copied below with a long body, and the same dialog with .dialog-scrollable to compare.
  2. Open the first dialog. If it fits, make the window shorter than it.
  3. Try to reach the footer.
  4. Reported as twbs/bootstrap#42459, closed as not planned: .dialog-scrollable is the documented way out. Fix proposed in twbs/bootstrap#42621, which adds min-height: max-content to .dialog. Bootstrap 5's modal scrolled as a whole.

Expected

The whole dialog stays reachable: it grows and scrolls with its backdrop, as Bootstrap 5's modal did, or its body scrolls as with .dialog-scrollable.

Actual

.dialog has a max-height and overflow: visible: the body and footer spill out of the dialog's box, past the bottom of the viewport, and :root.dialog-open stops the page from scrolling. The footer can't be reached.

Measured here: open a dialog
