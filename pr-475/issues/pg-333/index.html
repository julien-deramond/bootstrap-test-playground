Issue pg-333: --spacer does not drive --spacer-1 to --spacer-12

Steps to reproduce

  1. Compile Bootstrap with its defaults: $spacer is 1rem.
  2. After Bootstrap's stylesheet, override the token at runtime: :root { --bs-spacer: .75rem; }. This page does exactly that.
  3. Read the padding of the twelve boxes below, each set to var(--bs-spacer-N) and never to a .p-* utility, then compare the popover, the alert and the list group.

Expected

Every --spacer-N follows --spacer: with a 12px --spacer, step 3 is 6px (its factor, 0.5, times 12px), and every other step scales the same way. The popover, the alert and the list group shrink on both axes.

Actual

The twelve tokens keep the values Sass computed from the default $spacer (step 3 stays 8px, as .5rem). Only what reads var(--spacer) moves, so a component can follow the override on one axis and not the other.
