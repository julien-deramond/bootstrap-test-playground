Issue pg-201

Steps to reproduce

  1. Compile @include color-mode(dark) { .probe { outline: 3px solid; } } once with $color-mode-type: "media-query" and once with "data".
  2. Look at the probes below with the system in light, then in dark (the toolbar's color mode only sets data-bs-theme on <html>, so use the browser's emulation for the system).
  3. Compare the outline with the probe's own color mode.

Expected

The outline shows exactly where the probe is in dark mode, where light-dark() tokens resolve to their dark value, with either type and either system preference.

Actual

media-query follows the system and ignores data-bs-theme. data ignores the system, takes any dark ancestor for the nearest one and never matches the element itself.
